# Como publicar o CodeSprint no GitHub (sem terminal)

1. Entre na conta GitHub que será usada para o portfólio.
2. Acesse https://github.com/new
3. Em **Repository name**, digite `codesprint-quiz`.
4. Em **Description**, escreva: `Quiz interativo de HTML, CSS e JavaScript com níveis, cronômetro e ranking local.`
5. Selecione **Public** e crie o repositório.
6. Clique em **Add file → Upload files** e envie os arquivos soltos de dentro da pasta do projeto (não envie apenas o ZIP).
7. Clique em **Commit changes**.
8. Abra **Settings → Pages**; em **Source** escolha **Deploy from a branch**.
9. Selecione a branch **main**, a pasta **/(root)**, e clique em **Save**.
10. Após a publicação, abra a URL exibida em Pages. O formato costuma ser `https://USUARIO.github.io/codesprint-quiz/`.
11. Em **About** do repositório, cole o link publicado no campo **Website**.
12. Fixe o repositório no perfil e, quando tiver testado o projeto, publique também no LinkedIn.

**Se aparecer página 404:** confira se o arquivo `index.html` está na raiz do repositório, se a branch escolhida está correta e se a publicação concluiu.

**Tecnologias para o campo Topics:** `html`, `css`, `javascript`, `quiz-app`, `frontend`, `localstorage`, `responsive-design`.
